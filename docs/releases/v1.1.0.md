## What's new

- **Mixture solver (opt-in):** `RUN_BOT.bat --solver-mode mixture`. Instead of
  playing toward one guessed target score, it reads the opponent's scorecard,
  builds a probability distribution of their final score, and picks the move
  with the highest win probability averaged over that distribution. Exact ties
  are broken by exact expected score.
- **Exact expected-score table:** mean and variance of the remaining score for
  every scorecard state. Built in seconds on first use of the mixture mode and
  cached as `cpp/ev_table.bin` (16 MB).
- **About 40x faster tablebase generator** with bit-identical output, for anyone
  rebuilding the tablebase locally (about 20 minutes on 4 cores).
- The solver library now also builds and loads on Linux and macOS.
- New `scripts/run_mixture_evaluation.py` for paired head-to-head evaluation
  against a simulated opponent.

## Evaluation

10,000 paired games per row against a simulated opponent playing its own dice:

| Opponent | unified (default) | mixture | McNemar p |
|---|---|---|---|
| Expected-score-optimal (averages 254.6) | 47.2% wins | 51.1% wins | < 0.0001 |
| Weaker: 25% second-best moves (averages 216) | 68.6% wins | 71.5% wins | < 0.0001 |

The default solver mode is unchanged in this release.

## Windows quick start

1. Download and extract `aleatrix-solver-v1.1.0-windows-x64.zip`.
2. Install Python 3.12 or newer if needed.
3. Double-click `SETUP_WINDOWS.bat`.
4. Double-click `RUN_BOT.bat`.

The ZIP includes the prebuilt Windows x64 C++ runtime, so Git, CMake, and
Visual Studio are not required. The 5.57 GB tablebase is unchanged from v1.0.0;
setup downloads and verifies it from Hugging Face if it is not already present.

Tablebase: https://huggingface.co/datasets/YatzCore/aleatrix-solver-tablebase
